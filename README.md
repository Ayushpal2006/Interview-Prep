# Interview-Prep

A comprehensive, visually-rich SDE1 & Full-Stack Interview Preparation web application built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

Designed specifically for **visual thinkers**, featuring interactive SVG diagrams, live network simulations, coding practice arena, and assessment quizzes.

## 🚀 Live Deployments

- ⚡ **Vercel Production**: [https://interview-prep-iota-six.vercel.app](https://interview-prep-iota-six.vercel.app)
- 🌐 **GitHub Pages**: [https://ayushpal2006.github.io/Interview-Prep/](https://ayushpal2006.github.io/Interview-Prep/)

## 🎨 Core Visual Features

- 🌐 **Interactive Visual Network Lab**: Live topology switcher (Star, Ring, Bus, Mesh) with cable-cut simulation & packet flow tracking.
- 🎨 **Visual Concept Library**: 30+ custom interactive SVG diagrams covering:
  - **Computer Networks**: OSI 7 Layers vs TCP/IP 4 Layers, IPv4 Octets & Classes, HTTP vs HTTPS, DNS resolution, DHCP DORA flow, ARP, Hub vs Switch, Firewall, VPN Tunneling, Routing & Gateway.
  - **Data Structures & Algorithms**: Big-O visualizer, Two Pointers, Sliding Window, BFS/DFS Trees, Stacks, Hash Maps.
  - **System Design & DevOps**: Docker Containers vs VMs, Image Layering, Volumes, Compose.
  - **Databases & SQL**: Relational normalization, JOINs (Inner/Left/Right/Cross), Indexes, ACID transactions.
- 💻 **Browser-Based Practice Arena**: Live JavaScript code runner for classic interview coding problems with instant test suite feedback.
- ⏱️ **Assessment Mode**: Timed knowledge quiz mode with full scoring and detailed visual explanations.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 6
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 🏃 Local Setup & Run

```bash
npm install
npm run dev
```

Open `http://localhost:5173/` in your browser.
